Sou um desenvolvedor focado em **Front-end e UI/UX**, com uma base técnica bem completa em **Full Stack e IoT**. Gosto de entender como as coisas funcionam de ponta a ponta: desde a ideia visual no Figma até a tela final, passando pela integração com APIs REST e até sensores físicos.

### 🚀 Destaque de Projeto: TAGDOG
O **TAGDOG** (Plataforma de Monitoramento Pet) é um ótimo exemplo de como eu gosto de trabalhar, unindo hardware e interface:

- 🎨 **O meu Papel:** Prototipação visual (Figma), desenvolvimento da interface web principal (React) e arquitetura de hardware (ESP32/C++).
- ⚙️ **O Desafio:** Capturar dados em tempo real de sensores físicos, passar por uma API (Java/Spring Boot) e mostrar tudo isso de um jeito simples, bonito e responsivo na tela.
- 🏆 **O Resultado:** Uma aplicação entregue de ponta a ponta, construída com metodologias ágeis (Scrum), que vai literalmente da solda da placa até o último clique do usuário.
